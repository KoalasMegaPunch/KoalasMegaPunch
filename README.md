# 학생용 클래스 앱 (물리학 클래스)

핸드폰 브라우저에서 쓰는 학생용 앱입니다. **Google Apps Script 웹앱**으로 만들었습니다.
- 서버 비용 0원, 별도 호스팅 없음
- 모든 데이터는 **선생님 구글 스프레드시트**에 저장됨 (학생은 시트를 볼 수 없음)
- 학생은 앱 주소를 받아서 홈 화면에 추가해 앱처럼 사용

## 기능

| 기능 | 학생 | 선생님(마스터 계정) |
|---|---|---|
| 0. 계정 | 닉네임 + 비밀번호로 가입/로그인. 가입 때 이름·휴대폰번호 입력 → **선생님만 볼 수 있음**. 다른 학생에게는 닉네임만 보임 | 학생 목록(이름·번호·닉네임) 확인, 비밀번호 초기화, 계정 삭제 |
| 1. 수업 | 과목별·주차별 수업 내용, 수업 영상(링크 버튼), 숙제 확인. 기본은 "이번 주" | 앱에서 바로 수업 올리기/수정/삭제 |
| 반별 공지 | 공지 탭에서 내 반 공지 + 전체 공지 확인. 고정 공지가 맨 위, 새 공지는 탭과 반 이름에 숫자 배지 + NEW 표시 | 반 선택 또는 "전체(모든 반)"로 공지 쓰기/수정/삭제, 맨 위 고정 |
| 2. Zoom Clinic | 토·일 19~24시 중 1시간 단위로 신청/취소, 메모 남기기. 예약하면 **Zoom 입장 버튼**과 회의 ID·암호가 보임. 다른 학생이 누군지는 안 보이고 "마감"으로만 표시 | 시간별 신청자(이름·번호·메모) 확인, 취소. **[Zoom Clinic 시간표] 시트에 시간표 모양으로 자동 정리**, 원하면 이메일 알림 |
| 3. 질문 | 과목별 게시판에 **익명** 질문, 선생님 답변 확인. 옆 탭에서 과목별 **FAQ** 확인 | 답변 등록/수정, 질문을 클릭 한 번으로 FAQ에 등록, FAQ 직접 추가/수정 |
| 과목 관리 | — | 과목명 수정, 과목 추가, 순서 변경, 숨기기 (예: "겨울특강 물리학 개념(월금)") |

## 설치 방법 (10분)

1. **구글 스프레드시트 새로 만들기** (예: 이름 "물리학 클래스 앱")
2. 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 왼쪽 파일 목록에서:
   - `Code.gs` 내용을 모두 지우고 이 저장소의 [`src/Code.gs`](src/Code.gs) 내용을 붙여넣기
   - **+ → HTML** 로 파일을 만들고 이름을 정확히 `Index` 로 → [`src/Index.html`](src/Index.html) 내용 붙여넣기
   - (선택) 프로젝트 설정 ⚙️ → "appsscript.json 표시" 체크 후 [`src/appsscript.json`](src/appsscript.json) 내용 붙여넣기 — 시간대가 `Asia/Seoul` 이어야 합니다.
4. 💾 저장 후, 위쪽 함수 선택에서 `setup` 선택 → **실행**
   - 처음엔 권한 허용 창이 뜹니다 → 내 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
   - 스프레드시트에 시트들(설정, 학생, 과목, 수업, 공지, Zoom Clinic 예약, Zoom Clinic 시간표, 질문, FAQ)이 생깁니다.
5. 스프레드시트 **[설정] 시트**에서 `선생님 비밀번호`를 원하는 값으로 바꾸기 (처음엔 무작위 값)
6. Apps Script 화면 오른쪽 위 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL**이 학생들에게 줄 앱 주소입니다.
7. 학생들은 주소를 열고 → 공유 버튼 → **홈 화면에 추가** 하면 앱처럼 쓸 수 있어요.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 해야 학생 화면에 반영됩니다. (주소는 그대로 유지)

## 설정 바꾸기 ([설정] 시트)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 앱 이름 | 물리학 클래스 | 앱 상단 제목 |
| 선생님 비밀번호 | (무작위) | 바꾸면 기존 선생님 로그인은 자동 로그아웃 |
| 공지사항 | (비어있음) | 수업 탭 맨 위에 짧게 표시 (반별 공지는 앱의 공지 탭에서) |
| Zoom 링크 | (비어있음) | Zoom 회의 주소. **예약한 학생에게만** "Zoom 입장하기" 버튼으로 보임 |
| Zoom 안내 | (비어있음) | 회의 ID·암호 등. 예약한 학생에게만 보임 |
| Clinic 요일 | 토,일 | |
| Clinic 시작/종료 시각 | 19 / 24 | 19시~24시, 1시간 단위 |
| 시간당 정원 | 1 | 1:1 보충이면 1 |
| 예약 오픈 주수 | 2 | 이번 주 + 다음 주까지 신청 가능 |
| 1인 주당 최대 신청(시간) | 0 | 0 = 제한 없음 |
| 신청·취소 마감 | 1 | 시작 1시간 전까지 |
| 알림 받을 이메일 | (비어있음) | 적으면 보충 신청/취소, 새 질문 때 메일 발송 |

과목명은 앱의 **관리 탭**에서 바꾸는 게 가장 쉽습니다 ([과목] 시트에서 직접 고쳐도 됨).

## Zoom Clinic 시간표 시트

예약이 생기거나 취소될 때마다 **[Zoom Clinic 시간표]** 시트가 자동으로 다시 그려집니다.

```
시간         | 11/14 (토)            | 11/15 (일) | 11/21 (토) | ...
19:00~20:00 |                       |            |
20:00~21:00 | 홍길동 (뉴턴짱)         |            |
            | · 운동량 보존 질문       |            |
```

전체 기록(전화번호, 신청 시각 포함)은 **[Zoom Clinic 예약]** 시트에 남습니다. 시간표가 이상하면 스프레드시트 메뉴 **학생앱 → Zoom Clinic 시간표 새로고침**.

## 개인정보 / 보안

- 이름·전화번호는 서버에서 선생님 계정에만 내려보냅니다. 학생 화면 API 응답에는 아예 포함되지 않아요.
- 질문은 작성자 정보 없이 보여집니다. (선생님 화면에서도 기본은 익명. 선생님만 작성자를 보고 싶으면 `Code.gs` 맨 위 `SHOW_ASKER_TO_TEACHER` 를 `true` 로)
- 비밀번호는 salt + SHA-256 으로 저장되고, 로그인 토큰은 서명되어 있어 위조할 수 없습니다. 비밀번호를 바꾸거나 초기화하면 기존 로그인은 무효가 됩니다.
- 학생이 비밀번호를 잊으면: 관리 탭 → 학생 → 관리 → **비밀번호 초기화** (4자리 임시번호 발급)

## 개발용 (로컬 테스트)

`dev/` 폴더는 구글 서비스를 흉내 낸 로컬 테스트 도구입니다. 배포할 필요 없습니다.

```bash
npm test             # 백엔드 로직 테스트
npm run preview      # http://localhost:8787 에서 미리보기 (선생님 비밀번호는 콘솔에 출력)
npm run e2e          # 휴대폰 화면으로 전체 흐름 자동 테스트 + 스크린샷 (Playwright 필요)
```

## 업데이트 방법 (이미 설치한 경우)

Apps Script 에서 `Code.gs` 와 `Index` 내용을 새 버전으로 통째로 바꿔 붙여넣고 저장 →
**배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**. 새로 필요한 시트(예: [공지])는 처음 쓸 때 자동으로 만들어지고,
이전 버전의 [보충예약]/[보충시간표] 시트와 "보충 요일" 같은 설정은 **자동으로 Zoom Clinic 이름으로 바뀌며 데이터는 그대로** 유지됩니다.
